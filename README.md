### 🌐 About Me

> *"Every line of code is an opportunity to make someone's life easier or a business more successful."*

Saya adalah seorang **Full Stack Developer** yang berfokus pada pembuatan aplikasi web dan mobile berkinerja tinggi, berskala besar, serta memiliki desain UI/UX yang modern dan intuitif. 

- 🚀 **Clean Architecture & Scalability:** Membangun sistem modular dengan arsitektur backend andal (RESTful API, Real-time WebSockets, Microservices/Monorepo).
- 🎨 **Modern & Interactive UI:** Menerjemahkan kebutuhan bisnis menjadi antarmuka responsif dan estetik (*performance-driven & user-centric*).
- ⚡ **High Performance & Optimization:** Mengoptimalkan database query, caching layer (Redis), dan integrasi CI/CD & Docker.
- 🤝 **Continuous Learning:** Terus bereksplorasi dengan arsitektur modern, cloud technology, dan workflow terkini.
